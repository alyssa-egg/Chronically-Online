# Starter archive: editorial review

These 12 folders use existing published references, reformatted into interactive files. They are playable now. Broader new topic ideas remain in [CONTENT_ARCHIVE.md](CONTENT_ARCHIVE.md) for development and approval. Sound Files are written song/album clues. Era crossovers retain origins from earlier or later years. Edit server definitions and increment the folder version when changing a published file.
